# ADR 002 — Content inventory before Merkle optimization

Accepted for implementation. Protocol 4 uses keyset pages of operation UUID/content SHA-256 and bounded request/transfer batches, with explicit pass checkpoints and repeat passes for concurrent writes. Compare content, not just IDs/counts/max Lamport. Existing UUID uniqueness provides an index without changing signed JSON or physical schema. Prefer a linear streaming checkpoint to a Merkle DAG until measurements show that range diff complexity is necessary. Prove >10,000 and 100,000-operation behavior with synthetic measurements, including memory and main-actor responsiveness limits.

Implementation: immutable per-pass pages are materialized in LocalRecord cache rows (128 inventory entries, 32-operation/240,000-byte transfer batches). UUID/content digest additionally binds the outer certification digest. Capture races fail/retry; post-capture writes trigger a coalesced live hint and another pass. No Merkle DAG, maximum-Lamport completeness or 10,000-operation guard in V4. Process-orphaned cache pages are reclaimed; authoritative facts/staging/receipts are retained. The 100,000-fact benchmark uses actual independent Ed25519 signatures and two disk stores; transport and full-projection memory costs are reported separately from physical networking/GUI latency.
